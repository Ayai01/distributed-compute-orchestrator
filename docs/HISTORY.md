# DCO 版本日志

## 1.0.10 · 2026-11-19

- 分离启动准备、精确宽度握手与执行时限。回执记录准备耗时，固定内存按整任务报价。
- 按原 ID 原子登记运输副本退休。后台回收，重复或缺失 ID 幂等成功。

## 1.0.8 · 2026-11-18

- 普通准入返回聚合核数、各能力容量与单工程任务采样。隐藏运维路由和诊断中的设备地址。
- 任务标签按栏宽截断。结果归档及单文件领取与大输入上传分开排队。

## 1.0.7 · 2026-11-18

- 本地服务可用 `--no-dashboard` 在无窗口设备运行，启动和运行日志走标准输出与标准错误。Linux 服务收到停止信号时结束子进程并保留正常收尾。

## 1.0.6 · 2026-11-18

- 恢复 Windows 终端原生鼠标拖选和复制。选区有效时暂停面板重绘。

## 1.0.5 · 2026-11-18

- 总览和节点详情分别显示节点接口 IP 与中转入口。总览同时保留 CPU%、内存占用和能力。

## 1.0.4 · 2026-11-18

- 节点总览同时显示 CPU%、已用／总内存、IP／中转入口和能力。窄窗改用换行分页。

## 1.0.3 · 2026-11-18

- 统一中心、终端和 SDK 版本。总览显示各节点能力与可调度能力，保持节点、任务分页独立。
- 原生执行体按共享缓存和 ABI 派发。异常面板可回退到命令区，任务和结果按原 ID 保留。
- 保留本轮已验收的资源授权、学校共享资产和分段结果传输修复。退役的 AO 路由和端口从本机配置移除。

## 1.0.2 · 2026-11-18

- 总览固定在窗口顶部，命令区固定在底部。

## 1.0.1 · 2026-11-18

- 看板每秒刷新，锁忙时复用有时间戳的快照。活动页只保留在途任务，历史回执按原 ID 和费用归档。
