# DCO 版本日志

## 1.0.24 · 2026-11-19

- RTL/Chisel 作业默认绑定已选 worker 注册的 firtool。用户提交的显式编译环境沿原任务保留。

## 1.0.23 · 2026-11-19

- 默认环境称为 `python`。独立显示 `ng47`、`hsp` 和 `onnx`，RTL 总览标明 Chisel。
- 用实际 Chisel/RTL 工具探测决定准入。暂停接单、滚动版本和单核交接优化各自按实际状态处理。

## 1.0.22 · 2026-11-19

- 普通任务按一个固定能力包准入和派发，默认 `cpu`。工具、ABI、共享路径和原生缓存信息归运维端。
- 公开接口与终端能力列使用同一目录。旧调用映射至等价包，已受理原任务继续按原请求结清。

## 1.0.21 · 2026-11-19

- 公布 `single-core-phase-handoff`，由执行端协议确认。中心兼容已具备同等交接的 1.0.20 worker。
- 收件遇本地连接池繁忙时在原读取期限内重试，不产生新的原任务。

## 1.0.20 · 2026-11-19

- 批量简版状态直接读取原任务快照。SDK 遇到短时状态连接故障时保留已受理原 ID 并继续收件。
- 同一单核原任务在同步计算阶段之间沿用已确认的核；精确阶段一次确认新资源后启动。多核任务仍按需求归还资源。
- 终端进度有总量时显示百分比，否则显示已上报的阶段。

## 1.0.19 · 2026-11-19

- 公开健康、能力和准入读取现有快照。资产检查与准入登记使用已有的短时缓存保护，取消资产保留无需调度锁和单独的交接锁。

## 1.0.18 · 2026-11-19

- 默认 Python 部署固定 PyTorch 2.14.1，验收实际解释器、构建和张量运算。CPU 与 CUDA 13.0 使用各自的官方构建。
- 公开的容量与任务活动查询直接读取现有采样，避免等待派发和弹性调度锁。
- 取消原任务资产保留时立即回执，上传后的缓存整理交给后台维护。

## 1.0.17 · 2026-11-19

- 同阶段归还 CPU 时可保留已授权内存。SDK 继续重试未获确认的资源归还。
- 容器 CPU 百分比按其实际 CPU 配额采样，面板明确区分预留线程与使用率。

## 1.0.16 · 2026-11-19

- 中转上传和下载独立计速，增加普通大包并发，短派发、结果和控制保留各自连接。
- 资产缓存运行中按七天未命中和 64 GiB 总容量回收。校内共享副本损坏或缺失时由原输入恢复。
- 面板忙时继续显示最近快照并排队更新，避免弹性调度繁忙时读到长期过期的状态。

## 1.0.15 · 2026-11-19

- 增加 `elf-aapcs64` 原生载体准入，支持学校 ARM64 复用经等价验收的可执行件。

## 1.0.14 · 2026-11-19

- `pe64` 准入现有 64 位 PE 载体。`onnx-int8` 探测 CPU 整数卷积，并为请求该能力的任务绑定已验证的解释器。

## 1.0.13 · 2026-11-19

- 全量任务目录和原 ID 前缀搜索只向运维开放。工程通过已知原 ID 批量查询和领取结果。

## 1.0.12 · 2026-11-19

- 分开已授予内存和实测工作集。冷启动只占用已授予预算，核宽扩张按该阶段的真实采样报价。

## 1.0.11 · 2026-11-19

- 批量轮询可只返回状态和错误码，继续协商 gzip。状态稳定时将轮询间隔退避到 5 秒。

## 1.0.10 · 2026-11-19

- 分离启动准备、精确宽度握手与执行时限。回执记录准备耗时，固定内存按整任务报价。
- 按原 ID 原子登记运输副本退休。后台回收，重复或缺失 ID 幂等成功。

## 1.0.8 · 2026-11-18

- 普通准入返回聚合核数、各能力容量与单工程任务采样。隐藏运维路由和诊断中的设备地址。
- 任务标签按栏宽截断。结果归档及单文件领取与大输入上传分开排队。

## 1.0.7 · 2026-11-18

- 本地服务可用 `--no-dashboard` 在无窗口设备运行，启动和运行日志走标准输出与标准错误。Linux 服务收到停止信号时结束子进程并保留正常收尾。

## 1.0.6 · 2026-11-18

- 恢复 Windows 终端原生鼠标拖选和复制。选区有效时暂停面板重绘。

## 1.0.5 · 2026-11-18

- 总览和节点详情分别显示节点接口 IP 与中转入口。总览同时保留 CPU%、内存占用和能力。

## 1.0.4 · 2026-11-18

- 节点总览同时显示 CPU%、已用／总内存、IP／中转入口和能力。窄窗改用换行分页。

## 1.0.3 · 2026-11-18

- 统一中心、终端和 SDK 版本。总览显示各节点能力与可调度能力，保持节点、任务分页独立。
- 原生执行体按共享缓存和 ABI 派发。异常面板可回退到命令区，任务和结果按原 ID 保留。
- 保留本轮已验收的资源授权、学校共享资产和分段结果传输修复。退役的 AO 路由和端口从本机配置移除。

## 1.0.2 · 2026-11-18

- 总览固定在窗口顶部，命令区固定在底部。

## 1.0.1 · 2026-11-18

- 看板每秒刷新，锁忙时复用有时间戳的快照。活动页只保留在途任务，历史回执按原 ID 和费用归档。
