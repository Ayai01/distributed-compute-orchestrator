# DCO 重要变化

## 2026-10-20 RAM 实际用量与阶段公平

RAM 准入区分申报量和已采样进程树 RSS，归还高估的空预留；默认预算和实时系统余量分别配置。自动任务在安全阶段边界为同工程就绪任务腾出线程，排队按优先级及当前线程/份额补足；看板显示份额与优先级。Windows 端口所有者和停止进程改用原生 API，移除残留 WMI 启动阻塞。ku26s 补齐 ARH 固定 INT8 推理能力并验证 Linux 原生构建传输。

修复最近通知中纯数字四位短 hash 被误着黄色；方括号 ID 与任务表 ID 统一使用青色。

## 已完成的架构收敛

统一名称为 Distributed Compute Orchestrator，保留 remote_compute 包和 REMOTE_COMPUTE_* 协议兼容。对外端口统一 26133，hybrid 本机 worker 改为中心进程内调用；设备选择收敛到操作端和中心，科研工程使用汇总能力。

状态、输入和未领取成果从临时盘职责中分离，持久保存在普通磁盘；可重建临时物复用每设备唯一 8 GiB RAM 盘。网络恢复沿用原任务 ID，结果取回使用独立连接及续传。远端 CPU/RAM 协商改为 worker 本地 lease 和中心已有连接，旧反向回调与专项 live_patch 入口退役。

系统 Python 3.14 成为日常维护环境，setup 复用系统解释器；源码保留 3.7–3.15 兼容。所有常驻入口统一可见终端检查，重载保留原终端和任务状态。Windows 服务生命周期内的防自动休眠请求随退出释放。
